# Joyshelf ☀️

Sistema desenvolvido em Python e SQLite para registro e gerenciamento de livros, com o objetivo de permitir que o 
usuário mantenha uma estante virtual.

## Funcionalidades

- Cadastro de livros
- Listagem de livros cadastrados
- Filtragem por:
  - título
  - gênero
  - editora
  - autor
  - status de leitura
- Ordenação alfabética
- Atualização das informações de livros
- Exclusão de livros

## Tecnologias utilizadas

- Python 
- SQLite 
- PrettyTable (formatação de tabelas no terminal)

## Como executar

1. Clone o repositório:
```bash
git clone https://github.com/saemiuyeda/Joyshelf.git
```
2. Acesse a pasta do projeto:
```bash
cd Joyshelf
```
3. Instale a biblioteca prettytable:
```bash
pip install prettytable
```
4. Execute o programa:
```bash
python main.py
```

## Conceitos aplicados

- Desenvolvimento de aplicação CRUD
- Persistência de dados utilizando SQLite
- Operações SQL (CREATE, INSERT, SELECT, UPDATE e DELETE)
